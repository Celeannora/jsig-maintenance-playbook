# Appendix E — Definitions

Appendix E begins on JSIG page 376 according to the table of contents. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The parsed JSIG text defines an information system using CNSSI 4009 language as a discrete set of information resources organized for collection, processing, maintenance, use, sharing, dissemination, or disposition of information. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The parsed JSIG text defines reciprocity as a mutual agreement among participating enterprises to accept each other’s security assessments for reuse of information system resources or acceptance of assessed security posture for information sharing. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The parsed JSIG snippets define the Information System Owner as the organizational official responsible for procurement, development, integration, modification, operation, maintenance, and disposal of an information system. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)
