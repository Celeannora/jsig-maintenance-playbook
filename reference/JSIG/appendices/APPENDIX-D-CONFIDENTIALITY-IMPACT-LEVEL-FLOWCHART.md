# Appendix D — Confidentiality Impact Level Flowchart

Appendix D begins on JSIG page 375 according to the table of contents. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The parsed JSIG RMF text states that the confidentiality impact level for all SAP systems shall be moderate or high. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The parsed JSIG snippets state that TS//SAR or S//SAR confidentiality is moderate by default and is adjusted to high if any user lacks either the required security clearance or the required citizenship.
