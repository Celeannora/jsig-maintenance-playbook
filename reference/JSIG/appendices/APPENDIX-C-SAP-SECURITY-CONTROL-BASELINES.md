# Appendix C — SAP Security Control Baselines

Appendix C begins on JSIG page 341 according to the table of contents. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The JSIG RMF guidance states that SAP systems select baseline security controls identified from Appendix C, including the Classified Overlay security controls and SAP-defined organization values, corresponding to confidentiality, integrity, and availability impact values. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)

The JSIG snippets state that the Classified Overlay applies to all classified NSS including DoD SAP information systems and is considered part of the JSIG baseline control set. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)
