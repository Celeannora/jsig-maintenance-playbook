## Known JSIG-specific/non-tailorable controls

- AC-6(1): system endpoint protection shall not be tailored out. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)
- SA-22: unsupported system components was added to the baseline and is required on all SAP systems. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)
- SC-28: encryption of data at rest shall be implemented for all SAP systems. [JSIG PDF](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf)
