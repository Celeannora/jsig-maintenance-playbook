## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/PSO.md`)

1. Pull the personnel security tracking system's reinvestigation due-date report listing all cleared personnel and their last investigation completion date. — Expected result: a complete roster of cleared personnel with a last-investigation date for each. — Capture: the due-date report export with pull timestamp. — Stop/continue: if the report is missing personnel or dates, stop and remediate the tracking gap before reviewing partial data.
2. Calculate each individual's reinvestigation due date against the applicable periodic reinvestigation cycle (e.g., 5-year Tier 3/Secret, continuous evaluation enrollment) and identify anyone approaching or past due. — Expected result: a complete list of personnel approaching or past their reinvestigation due date (may be empty). — Capture: the due/overdue list. — Stop/continue: continue regardless of list size.
3. Verify enrollment status in the Continuous Evaluation (CE) program via DISS/JPAS for personnel eligible for CE in lieu of a scheduled periodic reinvestigation. — Expected result: every eligible individual's CE enrollment status is confirmed in DISS. — Capture: the DISS CE-enrollment check results. — Stop/continue: continue.
4. For personnel due, initiate the reinvestigation request in DISS (submit the e-QIP package) and record the submission date in the tracking system. — Expected result: every due individual has a submitted e-QIP package with a recorded submission date. — Capture: the DISS submission confirmation. — Stop/continue: continue.
5. Flag any overdue reinvestigation with no CE enrollment to the Personnel Security Officer for immediate action, including possible access suspension. — Expected result: every overdue/non-enrolled individual has an assigned remediation action. — Capture: the PSO notification/remediation record. — Stop/continue: if an overdue individual has no CE enrollment and no submitted reinvestigation, stop and escalate immediately — potential non-compliant continued access.
6. Update the reinvestigation tracking log with submission/due dates, obtain PSO sign-off, and file it in the personnel security records repository with the reviewer's name and date. — Expected result: complete, signed cycle package filed. — Capture: the filed tracking log. — Stop/continue: cycle complete.
