## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/ISSO.md`)

1. Export the current media-access authorization list (personnel authorized to access/use removable media, e.g. via the AD security group governing media-access privileges) using `Get-ADGroupMember`. — Expected result: a complete current media-access authorization export. — Capture: the exported list, with pull timestamp. — Stop/continue: if the export is incomplete, stop and remediate the collection gap before reviewing partial data.
2. Cross-reference the exported list against the current personnel roster and approved access-request tickets to confirm all listed individuals still require media access and hold current authorization. — Expected result: a discrepancy list (may be empty). — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
3. Review Trellix/McAfee ePO device-control policy or Windows Group Policy removable-storage restriction settings to confirm technical enforcement matches the approved authorization list. — Expected result: technical enforcement (ePO device control or GPO removable-storage restriction) matches the approved list. — Capture: the policy configuration review notes. — Stop/continue: continue, flagging any mismatch as a finding.
4. Remove or update authorization in Active Directory for any individual whose access is no longer justified (e.g. role change, termination) and document the change in a ticket. — Expected result: every unjustified authorization is removed/updated. — Capture: the ticket documenting each change. — Stop/continue: if an unexplained discrepancy suggests unauthorized media access already occurred, stop and escalate immediately per the Escalation block.
5. Spot-check a sample of recent removable-media usage events (ePO Threat Event Log or Windows Event Log) against the authorization list to confirm no unauthorized use occurred ([Trellix (McAfee) ePolicy Orchestrator Product Guide](http://b2b-download.trellix.com/PRODUCTS/naibeta-download/epo_460/previous%20postings/epo_460_beta2_productguide.pdf)). — Expected result: no unauthorized removable-media use found in the sample. — Capture: the spot-check results. — Stop/continue: continue.
6. Export the reconciled media-access authorization list and file it in the repository location specified in the Task Index alongside the ISSO's name and date. — Expected result: cycle record filed. — Capture: the filed reconciled list. — Stop/continue: cycle complete.
