## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/ISSO.md`)

This task's quarterly frequency is consistent with the tiered privileged-account review cadence ("no less often than quarterly") documented in the [HHS CMS MAC ARS](https://www.hhs.gov/guidance/sites/default/files/hhs-guidance-documents/CMS/117_Systems_security-MAC-ARS.pdf), used here as a federal cross-agency comparator for AC-2 privileged-account review timing.

1. Run `Get-ADGroupMember` against each privileged AD group (Domain Admins, Enterprise Admins, and system-specific privileged roles) to export the current membership list. — Expected result: a complete, current export of every privileged group's membership. — Capture: the exported membership list, with pull timestamp. — Stop/continue: if any privileged group cannot be enumerated (permissions/connectivity issue), stop and resolve access before proceeding.
2. Compare the exported membership against the last-approved privileged access roster and the current user account listing from `Get-ADUser`. — Expected result: a discrepancy list identifying additions, removals, and any account no longer active in the directory. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
3. Validate each privileged account against its supporting access authorization/justification record and confirm the account holder still requires that role. — Expected result: every privileged account is dispositioned as justified or unjustified. — Capture: disposition notes with supporting justification references. — Stop/continue: if any account shows no authorization record or belongs to separated/transferred personnel, treat as a finding and continue to step 4.
4. Identify and remove/disable any privileged accounts belonging to separated, transferred, or no-longer-justified personnel using Active Directory Users and Computers or the corresponding PowerShell cmdlet (e.g., `Disable-ADAccount`/`Remove-ADGroupMember`). — Expected result: no unjustified privileged account remains active. — Capture: the removal/disable action log. — Stop/continue: if an unjustified privileged account shows evidence of use after separation, stop and escalate immediately per the Escalation block below.
5. Document justification for retained privileged accounts and any removals performed. — Expected result: every retained and removed account has a documented rationale. — Capture: the justification/removal record. — Stop/continue: continue.
6. Export the reconciled privileged account list and file it in the repository location specified in the Task Index alongside the reviewer's name and date. — Expected result: a complete, dated, reconciled roster is filed for the cycle. — Capture: the filed roster and reviewer sign-off. — Stop/continue: cycle complete.
