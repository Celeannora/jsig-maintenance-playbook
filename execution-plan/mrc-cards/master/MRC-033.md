## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/PSO.md`). PE-2 requires the facility access list to be reviewed at least annually and individuals removed when access is no longer required, and PE-3 requires physical access devices to be inventoried and combinations/keys changed at least annually ([FedRAMP SSP Appendix A — Moderate Baseline, PE-2/PE-3](https://www.fedramp.gov/resources/templates/SSP-Appendix-A-Moderate-FedRAMP-Security-Controls.docx)); this card's Monthly cadence exceeds that FedRAMP floor for the access-list comparison itself.

1. Pull the current Authorized Access List (AAL) for each SAPF/restricted area from the facility access-management system. — Expected result: complete, unaltered current AAL export for every controlled area in scope. — Capture: the export file itself, with pull timestamp. — Stop/continue: if the export is incomplete (a gap in coverage), stop and remediate the collection gap before reviewing partial data.
2. Pull the current active-personnel roster (indoctrinated/briefed individuals) from the security officer's personnel tracking system. — Expected result: current, authoritative personnel roster in hand. — Capture: roster document/version. — Stop/continue: continue.
3. Compare the AAL against the active-personnel roster to identify individuals who have been debriefed, transferred, or terminated but remain on the AAL — PE-2 requires removing individuals from the facility access list when access is no longer required ([FedRAMP SSP Appendix A — Moderate Baseline, PE-2.d](https://www.fedramp.gov/resources/templates/SSP-Appendix-A-Moderate-FedRAMP-Security-Controls.docx)). — Expected result: a discrepancy list (may be empty) of stale AAL entries. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
4. Query the PACS door-controller configuration to confirm badge permissions match the current AAL for each controlled entry point. — Expected result: badge-permission configuration matches the AAL at every controlled entry point, or discrepancies are identified. — Capture: the PACS configuration extract. — Stop/continue: if any discrepancy suggests an active unauthorized permission, stop and escalate immediately per the Escalation block.
5. Remove or flag for removal any unauthorized entries and submit access-control system change requests to update badge permissions. — Expected result: every stale/unauthorized entry has a submitted change request. — Capture: the change-request ticket ID(s). — Stop/continue: continue.
6. Physically verify access control devices (cipher locks, biometric readers, mantraps) at each entry point are functioning, and confirm the physical-access-device inventory and any required combination/key changes are current per policy, during the inspection walk-through — PE-3 requires physical access devices to be inventoried and combinations/keys changed at least annually or upon a security-relevant event, loss, or personnel change ([FedRAMP SSP Appendix A — Moderate Baseline, PE-3.f–g](https://www.fedramp.gov/resources/templates/SSP-Appendix-A-Moderate-FedRAMP-Security-Controls.docx)). — Expected result: every device is functioning and the device inventory/combination-change record is current. — Capture: the walk-through checklist. — Stop/continue: if a device is malfunctioning in a way that could permit unauthorized entry, stop and escalate immediately.
7. Export the reconciled AAL and PACS configuration comparison and file it in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: evidence package filed and retrievable for audit. — Capture: the filed export and its repository path. — Stop/continue: cycle complete.
