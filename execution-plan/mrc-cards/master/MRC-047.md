## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/ISSM.md`)

AC-6(1) (Authorize Access to Security Functions) is one of JSIG's three non-tailorable controls ("System endpoint protection shall not be tailored out") per the [DCSA JSIG source document](https://www.dcsa.mil/portals/91/documents/ctp/nao/JSIG_2016April11_Final_(53Rev4).pdf), and this task's quarterly cadence aligns with the tiered privileged/security-function access review cadence in the [HHS CMS MAC ARS](https://www.hhs.gov/guidance/sites/default/files/hhs-guidance-documents/CMS/117_Systems_security-MAC-ARS.pdf).

1. Run `Get-ADGroupMember` and `Get-ADUser -Properties MemberOf` against accounts holding elevated or security-function privileges (e.g., audit log management, security policy administration) to export current assignments. — Expected result: a complete, current export of every elevated/security-function account assignment. — Capture: the exported assignment list, with pull timestamp. — Stop/continue: if any group/account cannot be enumerated, stop and resolve access before proceeding.
2. Review each assignment against the account holder's current job function and the least-privilege justification on file to confirm continued need. — Expected result: every assignment is dispositioned as justified or unjustified. — Capture: disposition notes with supporting justification references. — Stop/continue: continue regardless of disposition count.
3. Check GPMC/`Get-GPOReport` for User Rights Assignment settings (e.g., "Manage auditing and security log," "Debug programs") to confirm only authorized accounts hold sensitive rights ([Microsoft Learn — gpresult/Get-GPOReport](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/gpresult)). — Expected result: the GPO-applied User Rights Assignment settings match the authorized-account list from step 2. — Capture: the `Get-GPOReport` output/export. — Stop/continue: if a User Rights Assignment grants a right to an unauthorized account, treat as a finding and continue to step 4.
4. For any account no longer requiring elevated or security-function access, submit a CCB access-change request and remove the assignment via Active Directory. — Expected result: no unjustified elevated/security-function assignment remains. — Capture: the CCB request record and removal confirmation. — Stop/continue: if an unauthorized security-function assignment shows evidence of use, stop and escalate immediately per the Escalation block below.
5. Have the ISSM countersign the reassessed privileged/security-function access list. — Expected result: ISSM sign-off recorded. — Capture: the countersigned list. — Stop/continue: continue.
6. Export the updated access assignment report and file it in the repository location specified in the Task Index alongside the reviewer's name and date. — Expected result: a complete, dated, reviewed access assignment report is filed for the cycle. — Capture: the filed report and sign-off record. — Stop/continue: cycle complete.
