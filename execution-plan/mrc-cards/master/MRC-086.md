## 5. Procedure

**Pattern C — Update / Patch / Signature Refresh** (assignment from `runbooks/PSO.md`)

1. Pull the physical access device inventory (badge readers, cipher locks, keyed locks, safes) from the facility access-control system or badge log export. This satisfies the **at-least-annual** physical-access-device inventory requirement documented in [FedRAMP SSP Appendix A — Moderate Baseline, PE-3(f)](https://www.fedramp.gov/assets/resources/templates/SSP-A13-FedRAMP-Security-Controls-Moderate.docx). — Expected result: a current, complete device inventory export. — Capture: the inventory export, with pull date. — Stop/continue: continue.
2. Physically inspect each secure space/entry point and reconcile the observed devices and lock hardware against the inventory list, noting discrepancies. — Expected result: a discrepancy list (may be empty) between observed hardware and the inventory record. — Capture: the walk-through inspection notes. — Stop/continue: if a discrepancy suggests unauthorized hardware modification or a missing/compromised device, stop and escalate immediately per the Escalation block.
3. Change combinations on cipher locks/safes and re-key or reissue keys for keyed entry points per the facility's periodic rotation schedule, consistent with the **at-least-annual (or sooner upon a security-relevant event)** combination/key-change requirement in [FedRAMP SSP Appendix A — Moderate Baseline, PE-3(g)](https://www.fedramp.gov/assets/resources/templates/SSP-A13-FedRAMP-Security-Controls-Moderate.docx). — Expected result: all in-scope combinations/keys rotated for the cycle. — Capture: lock-change work orders and key-issue log signatures. — Stop/continue: continue.
4. Update the Active Directory-integrated physical access control system (or badge system) to revoke/reissue electronic credentials tied to changed hardware. — Expected result: electronic credentials reconciled with the newly rotated physical hardware. — Capture: the AD/badge-system change record. — Stop/continue: continue.
5. Photograph or log evidence of completed combination/key changes (e.g., lock-change work orders, key-issue log signatures). — Expected result: documented evidence for every rotated device. — Capture: photos/logs. — Stop/continue: continue.
6. Route the updated inventory and rotation log to the PSO for review and sign-off. — Expected result: documented approval or rejection with rationale. — Capture: approval record/signature. — Stop/continue: if rejected, return to step 3 for any unresolved item.
7. File the inventory, rotation log, and PSO sign-off in the repository location specified in the Task Index with the Facility Security Officer's name and date. — Expected result: cycle record filed. — Capture: the filed inventory and rotation log. — Stop/continue: cycle complete.
