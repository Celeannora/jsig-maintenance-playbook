## 5. Procedure

**Pattern A — Automated Monitoring / Scan Confirmation** (assignment from `runbooks/PSO.md`)

1. In Splunk (or the local environmental-monitoring/building-management-system (BMS) feed for the server room), query the current shift's logged temperature and humidity readings. — Expected result: readings for the full current cycle are present with no data gap. — Capture: exported readings/dashboard screenshot with timestamp. — Stop/continue: if the feed shows a data gap or the sensor/dashboard did not report, stop and open a missed-cycle ticket in the local ticketing/GRC system before proceeding.
2. Compare the logged readings against the facility's documented PE-14 operating-range thresholds (temperature and relative humidity limits defined in the facility's own environmental-controls policy or equipment specification) and flag any out-of-range excursion. — Expected result: readings are within the documented range, or every excursion is identified. — Capture: annotated comparison of readings vs. threshold. — Stop/continue: continue to step 3 regardless of findings; findings are documented, not gated, at this step.
3. If an alarm fired in the BMS/Splunk dashboard, confirm the Facility Security Officer's response and corrective action (e.g., HVAC service ticket) was logged. — Expected result: every alarm has a documented response and disposition. — Capture: alarm record and corrective-action ticket reference. — Stop/continue: if an excursion is ongoing and uncorrected, stop and escalate immediately per the Escalation block below.
4. Physically inspect the space's HVAC readout or local sensor display to cross-check against the Splunk/BMS-reported values for sensor accuracy. — Expected result: physical reading is consistent with the reported value (within expected sensor tolerance). — Capture: inspection note (reading observed, time, inspector). — Stop/continue: if physical and reported readings diverge significantly, treat as a sensor-malfunction finding and continue to step 5.
5. Note any sensor malfunction or maintenance need and open a facilities work order if required; determine CAT (I/II/III) for any excursion finding per organizational policy. — Expected result: any equipment/finding issue has an open work order or CAT assignment. — Capture: work-order ID or CAT assignment record. — Stop/continue: continue.
6. Export the environmental dashboard reading and any alarm/ticket record, and file cycle completion (date, reviewer, finding count, tracking IDs) in the repository location specified in the Task Index. — Expected result: cycle record filed. — Capture: the exported reading/record and log entry. — Stop/continue: cycle complete.
