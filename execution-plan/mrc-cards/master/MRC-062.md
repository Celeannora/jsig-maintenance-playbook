## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Privileged-Users.md`)

1. Pull the current physical facility diagram identifying all transmission line runs (network cabling, KVM extenders) and output-device locations (printers, fax, monitors displaying classified data) within the SCIF/SAPF from the local document-repository/GRC system. — Expected result: an up-to-date diagram covering every run and device in scope for the review period. — Capture: the diagram export, with pull timestamp/version. — Stop/continue: if the diagram is stale or missing coverage, stop and request an updated diagram from the Facility Security Officer before proceeding.
2. Physically inspect cable runs and junction/patch panels to confirm they are routed through protected/controlled areas or secured in conduit per the PE-4 access-control-for-transmission-medium requirement. — Expected result: every inspected run/panel is either in a controlled area or physically secured. — Capture: the walk-through checklist with pass/fail per run/panel. — Stop/continue: continue regardless of outcome; log every exception for step 5.
3. Verify each output device (printer, plotter, display) is located within an area restricted to authorized, cleared personnel, and check the Active Directory security group controlling access to the room/badge zone using `Get-ADGroupMember <GroupName>`. — Expected result: group membership matches the personnel authorized for that space, with no unexplained members. — Capture: command output (screenshot or redirected text) per checked group. — Stop/continue: continue; flag any membership mismatch as a discrepancy for step 5.
4. Confirm printer/output device access is not left unattended by observing during the walk-through and checking print-queue logs for evidence of unclaimed classified output. — Expected result: no unattended classified output observed or logged. — Capture: walk-through observation notes and any print-queue log excerpt reviewed. — Stop/continue: if unclaimed classified output is found unattended, stop and escalate immediately per the Escalation block.
5. Note any exposed cabling, unsecured patch panels, AD group-membership mismatches, or output devices in uncontrolled space, and open a corrective-action ticket with the Facility Security Officer for each. — Expected result: every exception has a named owner and a corrective-action ticket. — Capture: ticket ID(s) and disposition notes. — Stop/continue: if any exception represents an active, unremediated exposure of classified transmission or output, stop and escalate immediately per the Escalation block.
6. Export the walk-through checklist and access-control screenshot(s) and file them in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: complete evidence package filed for the cycle. — Capture: the filed checklist and screenshots. — Stop/continue: cycle complete.
