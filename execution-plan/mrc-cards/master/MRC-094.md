## 5. Procedure

**Pattern B — Manual Review of a List or Log** (underlying pattern; see step detail below for this control's specifics)

1. Pull the current PII inventory/data holdings list documenting each category of PII the system collects, stores, or processes. — Expected result: a complete, current PII inventory. — Capture: the inventory export, with pull date. — Stop/continue: if the inventory is incomplete or stale, stop and remediate the inventory gap before reviewing partial data.
2. For each PII data element, verify against current mission/business need whether the element is still required or could be reduced, masked, tokenized, or eliminated. — Expected result: every element has a documented necessity determination. — Capture: the annotated element-by-element review. — Stop/continue: continue regardless of findings.
3. Consult with the Data Owner and ISSM on any proposed minimization changes (e.g., truncating SSNs to last-4, purging obsolete fields, shortening retention of raw PII). — Expected result: documented consultation and agreed disposition for each proposed change. — Capture: consultation notes. — Stop/continue: continue.
4. Document minimization findings, including elements recommended for reduction or removal and the business justification for any PII retained in full. — Expected result: a complete findings report. — Capture: the findings report. — Stop/continue: continue.
5. Route the minimization review findings through the Information Owner/Steward for decision and, where system changes are needed, submit a change request to the CCB. — Expected result: documented decision on each finding; CCB change request filed where applicable. — Capture: the decision record and any CCB change-request ID. — Stop/continue: continue.
6. File the completed PII minimization review report in the privacy program repository per the Task Index, with reviewer name and date. — Expected result: complete, dated evidence package on file. — Capture: the filed report/location reference. — Stop/continue: cycle complete.
