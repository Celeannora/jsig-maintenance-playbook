## 5. Procedure

**Pattern B — Manual Review of a List or Log** (underlying pattern; see step detail below for this control's specifics)

1. Pull the current position risk designation roster from the personnel security/HR system, listing each billet's designated sensitivity/risk level (e.g., IT-I/II/III, Special-Sensitive, Critical-Sensitive). — Expected result: a complete, current-dated roster covering every billet in scope. — Capture: the roster export, with pull date. — Stop/continue: if the export is incomplete (missing billets), stop and remediate the roster-source gap before reviewing partial data.
2. Cross-reference each position against its current duties, system access level, and required investigation tier (T3, T5, T5R) to confirm the designation still matches actual responsibilities. — Expected result: every billet's designation is confirmed accurate or flagged as a discrepancy. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
3. Identify any position that has changed scope (e.g., gained privileged system access or SAP indoctrination duties) without a corresponding designation update. — Expected result: a discrepancy list (may be empty). — Capture: the discrepancy list. — Stop/continue: continue.
4. Coordinate with the ISSM to confirm designations align with the access each billet holds in the system access control list. — Expected result: documented ISSM concurrence or identified access/designation mismatch. — Capture: the ISSM coordination record. — Stop/continue: if a mismatch suggests a billet holds access beyond its designated risk tier, stop and escalate immediately per the Escalation block.
5. Update the position risk designation records for any billet requiring reclassification and route through the Personnel Security Officer for signature. — Expected result: every required reclassification is documented and signed. — Capture: the updated, signed roster entries. — Stop/continue: continue.
6. File the signed, current-year position risk designation roster in the personnel security records repository per the Task Index, with reviewer name and date. — Expected result: complete, dated evidence package on file. — Capture: the filed roster/location reference. — Stop/continue: cycle complete.
