## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/ISSM.md`)

1. Pull the current Rules of Behavior (RoB) document from the GRC/documentation repository and confirm it reflects current acceptable-use, remote-access, and removable-media requirements. — Expected result: current RoB version confirmed current or flagged for content update. — Capture: RoB version/date. — Stop/continue: continue.
2. Export the roster of all active system users requiring a signed RoB acknowledgment (e.g., via `Get-ADUser` against the authorized user group/OU, consistent with the assumed AD/Windows Server baseline environment). — Expected result: complete, unaltered roster of active users. — Capture: the roster export, with pull timestamp. — Stop/continue: if the export is incomplete (gap in coverage), stop and remediate the collection gap before reviewing partial data.
3. Cross-reference the user roster against the signed-acknowledgment tracking log (LMS or GRC repository) to identify personnel with missing, expired, or superseded acknowledgments. — Expected result: a discrepancy list of missing/outdated acknowledgments (may be empty). — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
4. Issue the current RoB for signature/acknowledgment to any personnel with missing or outdated acknowledgments, via the LMS or a documented signature process. — Expected result: every identified gap has an outstanding acknowledgment request issued. — Capture: the issuance log. — Stop/continue: continue.
5. Follow up on outstanding acknowledgments until 100% of active users have a current signed record on file. — Expected result: complete (100%) acknowledgment coverage for active users. — Capture: the follow-up log. — Stop/continue: if any individual's non-acknowledgment persists alongside continued privileged/system access, escalate immediately per the Escalation block rather than waiting for the routine follow-up cycle.
6. Route a summary compliance report to the ISSM for review. — Expected result: documented review/acceptance of the compliance report. — Capture: the report and review record. — Stop/continue: continue.
7. File the updated acknowledgment log and compliance report in the repository location specified in the Task Index with the ISSO's name and date. — Expected result: cycle record filed. — Capture: the filed log and report. — Stop/continue: cycle complete.
