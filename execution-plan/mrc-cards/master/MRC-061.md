## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Privileged-Users.md`)

1. Pull the current media inventory list from the removable-media log/register covering all classified media (CDs/DVDs, USB drives, external drives, backup tapes) in use during the quarter, in the local GRC/ticketing/media-accountability system. — Expected result: a complete, unaltered export covering every item logged since the last quarterly review. — Capture: the export file, with pull timestamp. — Stop/continue: if the export is incomplete (gap in coverage), stop and remediate the logging/collection gap before reviewing partial data.
2. Physically inspect a representative sample of media in storage/transit to confirm each item bears the required classification banner, control markings, and downgrading/declassification instructions per the applicable Security Classification Guide (SCG). — Expected result: every sampled item's physical marking matches SCG requirements. — Capture: the sample list with pass/fail marking notes per item. — Stop/continue: continue regardless of sample outcome; log every discrepancy for step 5.
3. For any BitLocker-protected removable drives in the sample, confirm the drive both displays the correct physical classification label and reports full protection using `manage-bde -status` or `Get-BitLockerVolume` ([Microsoft Learn BitLocker Operations Guide](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/operations-guide)) — check the `VolumeStatus`/`ProtectionStatus` fields against `FullyEncrypted`/`On`. — Expected result: physical label and reported encryption/protection status agree for every sampled BitLocker volume. — Capture: command output (screenshot or redirected text) per sampled drive. — Stop/continue: if a drive's reported status contradicts its physical marking (e.g., marked classified but `ProtectionStatus: Off`), stop and escalate immediately per the Escalation block — this is a potential unmarked/unprotected classified media finding, not a routine discrepancy.
4. Cross-check the marked classification level on each sampled item against the classification recorded in the media control register/SCI accountability log. — Expected result: a discrepancy list (may be empty) of unmarked, mismarked, or register-mismatched items. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
5. Document any unmarked, mismarked, or unmarked-but-required-exempt media (e.g., media within a closed/secured system per a documented waiver) and issue corrective tasking to the custodian of record. — Expected result: every discrepancy is either dispositioned with supporting justification (waiver on file) or escalated as a finding with a named custodian and corrective action. — Capture: disposition notes and corrective-tasking ticket ID(s). — Stop/continue: if any unexplained discrepancy suggests unmarked classified media left in an uncontrolled state, stop and escalate immediately per the Escalation block.
6. Export the sampled inventory checklist with marking findings and file it in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: complete evidence package filed for the cycle. — Capture: the filed checklist/report. — Stop/continue: cycle complete.
