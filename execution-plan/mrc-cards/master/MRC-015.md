## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Information-Owner-Steward.md`)

Applies to tasks where a person reviews an existing list, log, or record set against a baseline or policy (e.g., access lists, physical access logs, visitor records, privileged-account lists, audit records).

1. Pull the current accounting-of-disclosures log from the records-management/tracking system for all disclosures of personal information made outside the organization during the period, per AR-8. — Expected result: complete, unaltered export covering the full period since the last review. — Capture: the export file itself, with pull timestamp. — Stop/continue: if the export is incomplete (gap in coverage), stop and remediate the logging/collection gap before reviewing partial data.
2. Cross-reference each logged disclosure against the source authorization (data-sharing agreement, need-to-know approval, or legal request) on file. — Expected result: every disclosure entry has a corresponding authorization on file. — Capture: the annotated cross-reference. — Stop/continue: continue.
3. Verify the log captures the required elements — date, nature, purpose of disclosure, and recipient identity — for each entry. — Expected result: no entry is missing a required element. — Capture: annotated log noting any incomplete entries. — Stop/continue: continue regardless of finding count; findings are documented, not gated, at this step.
4. Confirm no disclosures were made without a corresponding log entry by sampling recent Active Directory/system access-export events (e.g., a sample pull of file-share or system export/print activity for the period) against the disclosure log. — Expected result: sampled access-export activity reconciles with logged disclosures, or every gap is identified. — Capture: the sampling comparison record. — Stop/continue: if an unlogged disclosure is found, stop and escalate immediately per the Escalation block below.
5. Address any gaps by adding missing entries and documenting the correction with Privacy Officer sign-off. — Expected result: log is complete and reconciled for the period. — Capture: correction record with sign-off. — Stop/continue: continue.
6. Export the reconciled accounting-of-disclosures log and file it, along with cycle completion details, in the repository location specified in the Task Index. — Expected result: cycle record filed. — Capture: the exported log and log entry. — Stop/continue: cycle complete.
