## 5. Procedure

**Pattern E — Documentation / Policy Review and Update** (underlying pattern; see step detail below for this control's specifics)

1. Pull all current privacy notices, System of Records Notices (SORNs), and Privacy Act statements applicable to the system from the privacy documentation repository and the Federal Register SORN listing. — Expected result: a complete set of current notices/statements/SORNs in hand. — Capture: the pulled documents, with pull date. — Stop/continue: continue.
2. Verify each notice/statement's routine uses, authority citations, and data categories still match the system's actual PII collection and processing as described in the current PIA. — Expected result: a documented match/mismatch determination for each notice. — Capture: the comparison notes. — Stop/continue: continue regardless of findings.
3. Confirm SORNs remain published and unexpired in the Federal Register; identify any requiring republication due to system or use changes. — Expected result: a confirmed publication-status list for every applicable SORN. — Capture: the Federal Register status check. — Stop/continue: continue.
4. Draft updated notice/statement/SORN language for any identified discrepancy, or a no-change certification memo if all remain accurate. — Expected result: draft ready for routing. — Capture: the draft. — Stop/continue: continue.
5. Route drafted updates through the Privacy Officer and Information Owner/Steward for approval, and submit any SORN revision through the agency's Federal Register publication process. — Expected result: documented approval and, where required, a submitted Federal Register publication request. — Capture: the approval record and publication submission confirmation. — Stop/continue: if rejected, return to step 4; do not publish an unapproved notice/SORN.
6. File the current, approved notices/statements/SORNs (or no-change memo) in the privacy program repository per the Task Index, with reviewer name and date. — Expected result: complete, dated evidence package on file. — Capture: the filed package/location reference. — Stop/continue: cycle complete.
