## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/ISSO.md`)

1. Run `Get-ADUser -Filter * -Properties MemberOf,Enabled,LastLogonDate` (or the equivalent GPMC/AD Users and Computers report) to export the current list of all non-privileged user accounts on the system. — Expected result: a complete, unaltered export of every enabled/disabled account with group membership and last-logon data. — Capture: the export file, with pull timestamp. — Stop/continue: if the export is incomplete (gap in coverage), stop and remediate the collection gap before reviewing partial data.
2. Cross-reference each account against the current access roster/personnel clearance list to confirm the user still requires access and holds the appropriate clearance/need-to-know. — Expected result: every account maps to an authorized, currently-cleared user. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count; log every unexplained account for step 5.
3. Run `Get-ADGroupMember` against standard user groups to confirm no non-privileged account has inadvertently inherited privileged/admin group membership. — Expected result: no non-privileged account appears in a privileged/admin group. — Capture: command output (screenshot or redirected text). — Stop/continue: if a non-privileged account is found with unexplained privileged group membership, stop and escalate immediately per the Escalation block.
4. Identify accounts with no logon activity for the review period (via `LastLogonDate`) and flag them for disablement per the account-management policy. — Expected result: a complete list of stale/inactive accounts (may be empty). — Capture: the flagged-accounts list. — Stop/continue: continue.
5. Route identified stale, unauthorized, or excess-privilege accounts to the ISSO for disablement/removal action and confirm closure. — Expected result: every flagged account has a documented disposition (disabled, removed, or justified exception) and closure confirmation. — Capture: disposition notes and closure confirmation. — Stop/continue: continue.
6. Export the account review report and disablement confirmation and file them in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: complete evidence package filed for the cycle. — Capture: the filed report. — Stop/continue: cycle complete.
