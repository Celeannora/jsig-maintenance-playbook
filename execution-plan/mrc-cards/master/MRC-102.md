## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/PSO.md`)

1. Pull the current roster of active third-party/contractor personnel with facility or system access from the Personnel Security Officer's tracking system or local GRC repository. — Expected result: complete, unaltered roster export covering every active contractor with access as of the review date. — Capture: the roster export with pull timestamp. — Stop/continue: if the roster export is incomplete (gap in coverage), stop and remediate the tracking-system gap before reviewing partial data.
2. Cross-check each contractor's file for a current, signed Non-Disclosure Agreement and confirm the applicable contract/task order includes the required personnel security clause (DD Form 254 or equivalent). — Expected result: every active contractor has an on-file NDA and a contract vehicle carrying the required security clause. — Capture: the NDA/clause-presence checklist per contractor. — Stop/continue: continue regardless of discrepancy count; log missing items as findings for step 5.
3. Confirm each contractor's investigation/clearance level and adjudication status is current by checking JPAS/DISS records against the access roster. — Expected result: every contractor's clearance level and adjudication status is verified current in DISS. — Capture: the DISS cross-check results. — Stop/continue: if any contractor's adjudication has lapsed or is not found in DISS, stop and escalate immediately — this is a potential unauthorized-access condition, not a routine finding.
4. Verify contractor security training completion (initial and annual refresher) via the training LMS completion roster. — Expected result: every active contractor shows a current initial/refresher training completion record. — Capture: the LMS completion export. — Stop/continue: continue.
5. Flag any contractor with an expired clearance, missing NDA, or lapsed training, and initiate access suspension or remediation with the sponsoring contract office. — Expected result: every flagged contractor has a remediation action and owner assigned. — Capture: the remediation/suspension request record. — Stop/continue: continue.
6. Document the review results in a compliance memo, obtain PSO sign-off, and file it in the personnel security records repository with the reviewer's name and date. — Expected result: complete, signed cycle package filed. — Capture: the filed compliance memo. — Stop/continue: cycle complete.
