## 5. Procedure

**Pattern A — Automated Monitoring / Scan Confirmation** (assignment from `runbooks/PSO.md`), adapted below for physical media-storage inspection plus a technical BitLocker-encryption spot-check. No reference doc on file addresses MP-4's physical/environmental storage-container requirements, so those steps are written generically per governance-card guidance; the encryption spot-check step is grounded to the [Microsoft Learn BitLocker Operations Guide](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/operations-guide).

1. Physically inspect the media storage area/container (safe, SCIF storage cabinet, or media library) housing classified/sensitive removable media and digital storage devices. — Expected result: storage area/container located and visually inspected with no unauthorized access indicators. — Capture: inspection notes/photos per local physical-security handling rules. — Stop/continue: if evidence of tampering or unauthorized access is found, stop and escalate immediately per the Escalation block.
2. Verify storage containers meet required physical protection standards (GSA-approved security container, combination lock control, container inventory log) per PE-3/MP-4 requirements. — Expected result: containers confirmed compliant against the organization's physical-security standard. — Capture: the container compliance checklist. — Stop/continue: if a container is non-compliant, stop and escalate to the Facility Security Officer for corrective action.
3. Confirm environmental controls (temperature, humidity, fire suppression) for the media storage room are within specification per facility monitoring records. — Expected result: all monitored environmental parameters are within specification for the review period. — Capture: the facility monitoring record excerpt. — Stop/continue: if a parameter is out of specification, stop and escalate to facilities/Facility Security Officer.
4. Pull the media inventory/control log and reconcile it against physically stored media to confirm no unaccounted-for items. — Expected result: every logged item is physically accounted for, and every physical item is logged. — Capture: the reconciled inventory. — Stop/continue: if any item is unaccounted for, stop and escalate immediately per the Escalation block.
5. Run `manage-bde -status` on a sample of removable/BitLocker-protected drives to confirm encryption remains enabled and keys are escrowed per policy ([Microsoft Learn — BitLocker Operations Guide](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/operations-guide)). — Expected result: every sampled drive reports Protection Status "On" with no unexpected "Suspended"/"Waiting for Activation" states. — Capture: the `manage-bde -status` output for each sampled drive. — Stop/continue: if a sampled drive shows protection off/suspended without an approved change record, stop and escalate immediately.
6. Note any discrepancies (missing media, uncontrolled access, environmental exceedance) and route to the Facility Security Officer for corrective action. — Expected result: every discrepancy has an assigned corrective-action owner. — Capture: the discrepancy/corrective-action log. — Stop/continue: continue.
7. Export the media storage inspection checklist and file it in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: evidence package filed and retrievable for audit. — Capture: the filed checklist and its repository path. — Stop/continue: cycle complete.
