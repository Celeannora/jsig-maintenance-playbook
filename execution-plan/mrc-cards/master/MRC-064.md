## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Information-Owner-Steward.md`)

1. Pull the complaint log/ticketing export from the privacy complaint intake system (or local GRC tracker) for all privacy-related complaints received in the quarter. — Expected result: a complete, unaltered export covering the full quarter since the last review. — Capture: the export file, with pull timestamp. — Stop/continue: if the export is incomplete (gap in coverage), stop and remediate the logging/collection gap before reviewing partial data.
2. Categorize each complaint by type (e.g., unauthorized disclosure, inaccurate record, denied access request) and calculate resolution time against the organization's complaint-handling SLA. — Expected result: every complaint has an assigned category and a computed resolution time (or open-aging value if unresolved). — Capture: the categorized worksheet. — Stop/continue: continue.
3. Compile trend statistics (volume by category, average time-to-resolve, recurring root causes) into the quarterly privacy complaint trend report. — Expected result: a complete trend report for the quarter. — Capture: the trend report. — Stop/continue: continue.
4. Compare current-quarter trends against the prior quarter's report to flag any emerging pattern requiring a process or training change. — Expected result: a documented comparison identifying any new or worsening trend (may be none). — Capture: the comparison notes. — Stop/continue: if a trend suggests a systemic control failure (e.g., a recurring unauthorized-disclosure category), stop and escalate immediately per the Escalation block rather than treating it as a routine finding.
5. Brief the trend findings and any recommended corrective actions to the Information Owner/Steward. — Expected result: documented acknowledgment/decision from the Information Owner/Steward on any recommended action. — Capture: the briefing record/decision memo. — Stop/continue: continue.
6. Export the trend report and file it in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: complete evidence package filed for the cycle. — Capture: the filed report. — Stop/continue: cycle complete.
