## 5. Procedure

*Authored procedure (from `runbooks/ISSO.md`, not a generic pattern) — no Pattern fits an always-on operational capability rather than a periodic check:*

1. Confirm the privacy incident response plan and intake channel (privacy incident mailbox/hotline logged in the local GRC/ticketing system) are active, staffed, and reachable per SE-2. — Expected result: capability confirmed live with on-call coverage in place. — Capture: on-call roster/coverage confirmation. — Stop/continue: if uncovered, stop and escalate the coverage gap to the ISSM immediately.
2. Pull the ticketing system's open/closed privacy-incident case list for the review period and confirm each case has an assigned Privacy Officer/IR Team Lead and a documented disposition. — Expected result: every case has an owner and a disposition (open/closed) recorded. — Capture: case list export. — Stop/continue: continue to Task #14/#17 handling for any case that also constitutes a security incident.
3. For any open privacy incident, verify required notifications (Information Owner/Steward, affected individuals if applicable, ISSM) were sent within the plan's required timeframe. — Expected result: all required notifications confirmed sent and timestamped. — Capture: notification records/timestamps. — Stop/continue: if a required notification is overdue, stop and escalate to the ISSM immediately.
4. Verify breach-response actions (containment, harm assessment, notification determination) are documented in the case record per the privacy incident response plan, coordinating triage with the Information Owner/Steward (Accountable party). — Expected result: each case record documents containment/assessment/notification-determination steps taken. — Capture: case record annotations. — Stop/continue: continue.
5. Confirm the case tracking log ties each incident to any related accounting-of-disclosures ([MRC-015](MRC-015.md)) or records-retention entries as required. — Expected result: cross-references present where applicable. — Capture: cross-reference note in the case record. — Stop/continue: continue.
6. Export the case list/ticket export and file it, along with cycle completion details (date, reviewer, finding count), in the repository location specified in the Task Index. — Expected result: cycle record filed. — Capture: the exported case list and log entry. — Stop/continue: cycle complete.
