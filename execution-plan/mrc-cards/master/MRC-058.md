## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Privileged-Users.md`)

1. Run a Tenable Nessus credentialed compliance/configuration-audit scan against the applicable DISA STIG audit file for the in-scope systems (a Policy Compliance Auditing or Advanced Scan template with the relevant STIG audit file selected on the scan's Compliance tab) ([Tenable Nessus User Guide / Compliance Checks Reference](https://docs.tenable.com/nessus/10_12/Content/PDF/Nessus_10_12.pdf)). — Expected result: the scan completes and returns per-check Pass/Fail/Warning results. — Capture: the scan job record. — Stop/continue: if the scan fails to complete (e.g. credential failure), stop and remediate before proceeding.
2. Export the Tenable scan results report showing pass/fail status per STIG configuration item, optionally generating the XCCDF result file for import into a viewer such as DISA STIG Viewer ([Tenable Nessus User Guide / Compliance Checks Reference](https://docs.tenable.com/nessus/10_12/Content/PDF/Nessus_10_12.pdf)). — Expected result: an exported report enumerating every STIG check's result. — Capture: the exported Nessus/XCCDF report. — Stop/continue: continue.
3. Cross-check any Group Policy-enforced baseline settings using `Get-GPOReport` or `gpresult /h` on a sample of systems to confirm the GPO settings match the approved baseline ([Microsoft Learn — gpresult / Get-GPOReport reference](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/gpresult)). — Expected result: sampled systems' applied GPOs match the approved baseline, with no unexpected denied/missing GPOs. — Capture: the `gpresult`/`Get-GPOReport` output per sampled system. — Stop/continue: continue, flagging any mismatch as a finding.
4. Review Trellix/McAfee ePO Policy Compliance queries (Menu > Reporting > Queries, Policy Management feature group) to confirm endpoint configuration policies are applied and reporting compliant across the managed asset inventory ([Trellix (McAfee) ePolicy Orchestrator Product Guide](http://b2b-download.trellix.com/PRODUCTS/naibeta-download/epo_460/previous%20postings/epo_460_beta2_productguide.pdf)). — Expected result: managed endpoints report compliant policy status. — Capture: the exported ePO compliance query results. — Stop/continue: continue.
5. For any finding showing configuration drift from baseline, open a remediation ticket and route any proposed baseline change through the CCB for approval. — Expected result: every drift finding has a ticket and, if a baseline change is proposed, a CCB ticket number. — Capture: the ticket/CCB record. — Stop/continue: continue.
6. Export the Nessus and ePO compliance reports and file them in the repository location specified in the Task Index alongside the System Administrator's name and date. — Expected result: cycle record filed. — Capture: the filed compliance reports. — Stop/continue: cycle complete.
