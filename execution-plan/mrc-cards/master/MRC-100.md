## 5. Procedure

**Pattern B — Manual Review of a List or Log** (underlying pattern; see step detail below for this control's specifics)

1. Pull the facility's current TEMPEST/emanations security (EMSEC) assessment or countermeasures review approved for the SAPF from the physical security records repository. — Expected result: current, approved assessment/review in hand, with its validity/expiration date. — Capture: the assessment document version/date. — Stop/continue: if no current approved assessment exists or it has expired, stop and escalate the certification gap before proceeding with a routine inspection.
2. Physically inspect the SAPF perimeter, RF shielding, filtered power/signal lines, and equipment placement (e.g., red/black separation) for compliance with the site's approved TEMPEST countermeasures plan. — Expected result: a documented compliant/non-compliant finding for each inspected element. — Capture: the inspection checklist/notes. — Stop/continue: continue regardless of findings.
3. Verify inspection/test zone (ITZ) boundaries and any required TEMPEST test measurements are current and within the certification validity period; coordinate with the Certified TEMPEST Technical Authority (CTTA) if recertification is due. — Expected result: a documented confirmation of ITZ/certification currency, or an initiated recertification request. — Capture: the ITZ/certification status record. — Stop/continue: if certification has lapsed, stop routine sign-off and escalate the recertification requirement immediately.
4. Photograph any observed deviations (e.g., unshielded penetrations, unauthorized equipment relocation) for the inspection record. — Expected result: a complete photographic record of every deviation found. — Capture: the photographs, labeled and dated. — Stop/continue: continue.
5. Coordinate with the ISSM to confirm no new IT equipment or cabling introduced since the last review has created an information leakage pathway. — Expected result: documented ISSM confirmation or an identified new pathway requiring remediation. — Capture: the ISSM coordination record. — Stop/continue: if a new leakage pathway is confirmed, stop and escalate immediately per the Escalation block.
6. Document findings and route any required remediation or CTTA recertification request through the Facility Security Officer to the PSO for approval. — Expected result: documented approval, rejection, or remediation assignment. — Capture: the routing/approval record. — Stop/continue: continue.
7. File the TEMPEST/information-leakage inspection report and photographs in the physical security records repository per the Task Index, with reviewer name and date. — Expected result: complete, dated evidence package on file. — Capture: the filed report/photo package/location reference. — Stop/continue: cycle complete.
