## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/PSO.md`). PE-6 requires physical access logs to be reviewed **at least monthly** ([FedRAMP SSP Appendix A — Moderate Baseline, PE-6.b](https://www.fedramp.gov/resources/templates/SSP-Appendix-A-Moderate-FedRAMP-Security-Controls.docx)), which matches this card's Monthly frequency.

1. Pull the electronic physical access control system (PACS) badge-swipe log for the SAPF/restricted area covering the review month, using the facility's PACS management console or reporting export function. — Expected result: a complete, unaltered badge-swipe export covering every day of the review month with no collection gaps. — Capture: the export file itself, with pull timestamp. — Stop/continue: if the export is incomplete (a gap in coverage), stop and remediate the logging/collection gap before reviewing partial data.
2. Pull the current Authorized Access List (AAL) for the area from the facility access-management system as the review baseline. — Expected result: current, approved AAL in hand. — Capture: baseline AAL document/version. — Stop/continue: continue.
3. Cross-reference every badge-swipe entry against the AAL to flag any entries by personnel not on the list. — Expected result: a discrepancy list (may be empty) of unauthorized-appearing entries. — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
4. Review the PACS alarm/exception log (forced-door, held-door, propped-door, badge-reader-tamper events) for the same period, and correlate any after-hours or anomalous access events with approved visit requests or on-call schedules. — Expected result: every alarm/exception event is either explained by an approved visit/on-call record or identified as unexplained. — Capture: the annotated alarm/exception log with dispositions. — Stop/continue: if any unexplained discrepancy or alarm suggests unauthorized physical access, stop and escalate immediately per the Escalation block, consistent with PE-6's requirement to coordinate review findings with the organizational incident response capability ([FedRAMP SSP Appendix A — Moderate Baseline, PE-6.c](https://www.fedramp.gov/resources/templates/SSP-Appendix-A-Moderate-FedRAMP-Security-Controls.docx)).
5. Notify the Facility Security Officer of any unresolved discrepancies for follow-up action. — Expected result: every unresolved discrepancy has an assigned follow-up owner. — Capture: notification record/ticket. — Stop/continue: continue.
6. Document findings in the PE-6 monitoring log, noting any incidents opened. — Expected result: a complete findings record for the cycle, including zero-finding cycles. — Capture: the monitoring-log entry. — Stop/continue: continue.
7. Export the PACS log review summary and file it in the repository location specified in the Task Index, alongside the reviewer's name and date. — Expected result: evidence package filed and retrievable for audit. — Capture: the filed export and its repository path. — Stop/continue: cycle complete.
