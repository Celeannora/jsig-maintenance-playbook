## 5. Procedure

**Pattern B — Manual Review of a List or Log** (assignment from `runbooks/Privileged-Users.md`)

1. Export the current remote-access authorized-user list via `Get-ADGroupMember` on the designated remote-access security group(s) and compare it against the VPN/RAS server's active session and authorization configuration. — Expected result: a complete current remote-access authorization export. — Capture: the exported group-membership list, with pull timestamp. — Stop/continue: if the export is incomplete, stop and remediate the collection gap before reviewing partial data.
2. Export the current wireless-access authorized-device/user list from the wireless controller or NPS (Network Policy Server) RADIUS configuration. — Expected result: a complete current wireless-access authorization export. — Capture: the exported list. — Stop/continue: continue.
3. Cross-reference both lists against the current personnel roster and approved access-request tickets to identify any account that should have been removed (terminated, transferred, or expired access). — Expected result: a discrepancy list (may be empty). — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
4. Remove or disable via Active Directory any remote-access or wireless-access authorization no longer justified, and document the change in a ticket. — Expected result: every unjustified authorization is removed/disabled. — Capture: the ticket documenting each change. — Stop/continue: if an unexplained discrepancy suggests unauthorized access, stop and escalate immediately per the Escalation block instead of only logging a routine ticket.
5. Confirm remote-access and wireless-access configurations still enforce required controls (e.g. MFA, encryption) per AC-17/AC-18 requirements. — Expected result: configuration confirmed compliant with required controls. — Capture: the configuration review notes. — Stop/continue: continue.
6. Export the reconciled authorization lists and file them in the repository location specified in the Task Index alongside the Network Administrator's name and date. — Expected result: cycle record filed. — Capture: the filed reconciled lists. — Stop/continue: cycle complete.
