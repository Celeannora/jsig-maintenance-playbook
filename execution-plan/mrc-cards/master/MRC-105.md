## 5. Procedure

**Pattern G — Retention / Disposal** (assignment from `runbooks/SCA.md`)

1. Pull the current control assessment tracking matrix (POA&M/assessment schedule) from the GRC repository listing every control in the system security plan and its last assessment date. — Expected result: a complete matrix covering every SSP control with a last-assessed date. — Capture: the tracking matrix export. — Stop/continue: if the matrix has missing/blank last-assessed dates for any control, stop and remediate the tracking gap before proceeding.
2. Cross-reference the matrix against the "at least once in a three-year period" control-assessment rule ([FedRAMP ConMon Playbook](https://www.fedramp.gov/assets/resources/documents/CSP_Continuous_Monitoring_Performance_Management_Guide.pdf)) to identify any control not assessed via a Nessus scan, manual review, or interview within the past 3 years. — Expected result: a complete list of controls past or approaching the 3-year window (may be empty). — Capture: the past-due/approaching-due control list. — Stop/continue: continue regardless of list size.
3. Run or pull the most recent Nessus credentialed/compliance scan results ([Tenable Nessus User Guide](https://docs.tenable.com/nessus/10_12/Content/PDF/Nessus_10_12.pdf)) and Splunk continuous-monitoring dashboard exports to confirm technical controls have current assessment evidence. — Expected result: every technical control has a corresponding scan/dashboard evidence artifact dated within the cycle. — Capture: the scan report/dashboard export set. — Stop/continue: continue.
4. For controls lacking recent technical scan coverage (e.g., PS, PE, MP families), confirm an assessor interview, document review, or physical inspection was conducted and recorded within the cycle. — Expected result: every non-technical control has a recorded assessment method and date. — Capture: the interview/document-review/inspection record. — Stop/continue: continue.
5. Flag any control past its 3-year assessment window and schedule it with the SCA/SCAR for immediate assessment. — Expected result: every past-due control has a scheduled assessment date and owner. — Capture: the scheduling record. — Stop/continue: if a control has gone significantly beyond the 3-year window with no scheduled remediation, stop and escalate to the SCA immediately.
6. Update the control assessment tracking matrix with the current cycle's completion dates, obtain SCA sign-off, and file it in the assessment records repository with the reviewer's name and date. — Expected result: complete, signed, updated matrix filed. — Capture: the filed matrix. — Stop/continue: cycle complete.
