## 5. Procedure

**Pattern G — Retention / Disposal** (assignment from `runbooks/Privileged-Users.md`)

1. Run `Get-ADUser` and `Get-ADComputer` (PowerShell Active Directory module) filtered on disabled/deleted status and `LastLogonDate` against the domain to pull all identifiers (usernames, SIDs, computer accounts) retired within the current cycle. — Expected result: a complete list of identifiers retired this cycle. — Capture: the exported query results (CSV or transcript). — Stop/continue: continue regardless of list size.
2. Query the AD Recycle Bin (or equivalent tombstone/reuse history) to confirm no retired username or SID has been reassigned to a new user or system within 2 years of retirement. — Expected result: zero identifier collisions found within the 2-year window. — Capture: the Recycle Bin/tombstone query output. — Stop/continue: if any collision is found, stop and escalate immediately — this is an IA-4 control violation, not a routine finding.
3. Review the account provisioning process/naming convention documentation to confirm new-account creation procedures block reuse of any identifier within the 2-year window (e.g., unique suffixing, permanent disable rather than delete). — Expected result: the provisioning procedure is confirmed to structurally prevent reuse within the required window. — Capture: the procedure excerpt reviewed. — Stop/continue: continue.
4. Spot-check a sample of newly created accounts against the retired-identifier list to confirm none collide with an identifier retired in the last 2 years. — Expected result: zero collisions in the sample. — Capture: the sample comparison results. — Stop/continue: if a collision is found, treat as a control violation per step 2's stop/continue guidance.
5. Document any violation of the reuse restriction as a finding and open a remediation ticket with the System Administrator in the local GRC/ticketing system. — Expected result: every violation has a tracking ID and owner. — Capture: ticket ID(s). — Stop/continue: continue.
6. Export the AD query results and reuse-verification findings, and file them in the identity management records repository with the reviewer's name and date. — Expected result: complete, signed cycle package filed. — Capture: the filed export/findings package. — Stop/continue: cycle complete.
