## 5. Procedure

**Pattern C — Update / Patch / Signature Refresh** (assignment from `runbooks/Privileged-Users.md`)

1. In the ePO console, run the built-in **VSE: DAT Deployment** query (**Menu | Reporting | Queries**, per the [Trellix ePolicy Orchestrator Product Guide](http://b2b-download.trellix.com/PRODUCTS/naibeta-download/epo_460/previous%20postings/epo_460_beta2_productguide.pdf)) to confirm all managed endpoints report the current-day DAT file and engine version per SI-3, consistent with [IRS Publication 1075](https://www.irs.gov/pub/irs-pdf/p1075.pdf)'s not-less-than-daily malicious-code signature update-check standard used here to frame this task's Daily cadence. — Expected result: DAT Deployment query shows all managed endpoints on the current-day signature/engine version. — Capture: exported query results (CSV/PDF). — Stop/continue: continue to step 2 regardless of result; non-compliant endpoints are handled there.
2. Run the ePO Asset/Software Inventory report (Query Builder, **System Management > Managed Systems** result type) to identify any endpoints that failed to check in or update within the last Agent Wake-Up cycle. — Expected result: complete list of non-reporting/stale endpoints (may be empty). — Capture: inventory report export. — Stop/continue: continue.
3. For non-compliant endpoints, force an Agent Wake-Up call and re-verify signature update completion by re-running the DAT Deployment query. — Expected result: previously non-compliant endpoints now show current DAT/engine version, or a hardware/connectivity finding is documented for any that remain non-compliant. — Capture: re-query output. — Stop/continue: if an endpoint remains non-compliant after wake-up, document it as an open finding and continue.
4. Review the ePO Threat Event Log (**Menu | Reporting | Threat Event Log**) for the last 24 hours for any malware detections that were not automatically remediated, and confirm analyst follow-up. — Expected result: every unremediated detection has documented analyst follow-up. — Capture: Threat Event Log export/screenshot. — Stop/continue: if an unremediated detection shows active compromise indicators, stop and escalate immediately per the Escalation block below.
5. Check the ePO Policy Compliance query results to confirm on-access scanning remains enabled organization-wide. — Expected result: Policy Compliance query shows 100% (or organization-defined threshold) on-access-scanning compliance. — Capture: Policy Compliance query export. — Stop/continue: if compliance falls under threshold, apply the update/reconfiguration through the organization's change-control process before closing the cycle.
6. Log cycle completion (date, prior/new DAT versions, verifier) in the repository location specified in the Task Index. — Expected result: cycle record filed. — Capture: the log entry. — Stop/continue: continue.
7. Export the ePO DAT compliance dashboard and Threat Event Log summary and file them in the repository location specified in the Task Index alongside the reviewer's name and date. — Expected result: evidence package complete. — Capture: the exported dashboard/log files. — Stop/continue: cycle complete.
