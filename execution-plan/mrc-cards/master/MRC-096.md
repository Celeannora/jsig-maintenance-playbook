## 5. Procedure

**Pattern B — Manual Review of a List or Log** (underlying pattern; see step detail below for this control's specifics)

1. Pull the current list of internal users/business units and external third parties (contractors, agencies, cross-program partners) with authorized access to system information. — Expected result: a complete, current access/sharing-party list. — Capture: the list export, with pull date. — Stop/continue: if the export is incomplete, stop and remediate the source gap before reviewing partial data.
2. Review data-sharing agreements, MOUs/MOAs, and interconnection security agreements (ISAs) on file for each third party to confirm they remain current and cover the actual data being shared. — Expected result: a documented current/expired/missing status for every agreement. — Capture: the agreement-status review notes. — Stop/continue: continue.
3. Compare actual observed information flows (e.g., recent data transfer/export logs or access requests) against what is authorized under the internal-use policy and each sharing agreement. — Expected result: a discrepancy list (may be empty). — Capture: the annotated comparison. — Stop/continue: continue regardless of discrepancy count.
4. Flag any sharing arrangement lacking a current signed agreement, or any internal use exceeding the documented purpose, for corrective action. — Expected result: every discrepancy is dispositioned with supporting justification or flagged as a finding. — Capture: the disposition notes. — Stop/continue: if any unauthorized sharing or use is found, stop and escalate immediately per the Escalation block.
5. Coordinate with the ISSM and Information Owner/Steward to remediate gaps (terminate unauthorized sharing, execute/renew agreements as needed). — Expected result: a remediation plan/action for each flagged gap. — Capture: the remediation coordination record. — Stop/continue: continue.
6. File the compliance review findings and any updated/executed agreements in the privacy program repository per the Task Index, with reviewer name and date. — Expected result: complete, dated evidence package on file. — Capture: the filed package/location reference. — Stop/continue: cycle complete.
