Appendix A -- Active Directory Group Name Resolution (Interactive Query)

Checklist items in Section 5 name groups generically ("Domain Admins", "Server Admins", "Workstation Administration", "Network Engineers"). Real environments frequently use different actual group names for the same role. Rather than hardcode exact names, resolve each role through a small per-environment config file, with an Active Directory search fallback when a configured name isn't found:

Per-environment config file

# ad-group-map.json (per-environment, editable)
{
  "Domain Admins": ["Domain Admins"],
  "Server Admins": ["Server Admins", "Tier-1-Admins"],
  "Workstation Administration": ["Workstation Administration", "WKSTN-Admins"],
  "Network Engineers": ["Network Engineers", "NetEng"]
}

Fallback command (native -- RSAT ActiveDirectory module)

# Native -- PowerShell ActiveDirectory module (RSAT)
Get-ADGroup -Filter "Name -like '*Admin*'" | Select-Object Name, DistinguishedName

# If a configured name in ad-group-map.json isn't found on this domain,
# fall back to this wildcard search, prompt the operator to pick the
# correct match, then offer to save it back to the config file for
# future runs on the same domain.
