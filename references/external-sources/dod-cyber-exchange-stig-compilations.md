## Page Content (relevant excerpt)

The DoD Cyber Exchange publishes STIG/SRG **Library Compilations** as consolidated .zip files containing every current Security Requirements Guide (SRG) and Security Technical Implementation Guide (STIG).

**Library Compilation .zip files will be updated and released during each SRG-STIG Update Release Cycle.**

This means the compiled library bundle is not updated ad hoc — it follows DISA's periodic (quarterly) SRG/STIG update release cycle, the same cadence referenced for individual STIG updates in the JSIG research file's configuration-management (CM-6/CM-2) cadence discussion. Individual STIGs may also be updated and re-released outside the compilation cycle when urgent security issues are identified, but the consolidated Library Compilation itself is tied to the scheduled update release cycle.
